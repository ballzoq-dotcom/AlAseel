# تطبيق صالون الأصيل (أندرويد)

تطبيق أندرويد يعرض موقع صالون الأصيل. الموقع مدمج داخل التطبيق نفسه، فيفتح فوراً حتى بدون إنترنت، وصفحة الحجز (Setmore) تفتح داخل التطبيق. روابط الاتصال والخريطة وإنستغرام وفيسبوك تفتح في تطبيقاتها على الهاتف.

- اسم الحزمة: `com.alaseel.salon`
- يعمل على أندرويد 8.0 فما فوق
- شاشة بداية، أيقونة متكيّفة، سحب للأسفل للتحديث، شاشة عند انقطاع الإنترنت، زر الرجوع يرجع داخل الصفحات

## الطريقة الأولى: بناء الـ APK تلقائياً عبر GitHub (بدون تثبيت أي شيء)

1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كما هي.
2. افتح تبويب **Actions** في المستودع. يبدأ البناء تلقائياً (أو اضغط **Run workflow**).
3. بعد انتهاء البناء (حوالي 5 دقائق) افتح التشغيل الأخير، وحمّل **alaseel-apk** من قسم Artifacts.
4. فك الضغط، انقل `app-debug.apk` إلى الهاتف وثبّته (فعّل "التثبيت من مصادر غير معروفة" إذا طلب الهاتف ذلك).

## الطريقة الثانية: Android Studio

1. افتح المجلد في Android Studio (File > Open).
2. انتظر انتهاء المزامنة، ثم Build > Build App Bundle(s) / APK(s) > Build APK(s).
3. للنشر على Google Play: Build > Generate Signed App Bundle، وأنشئ مفتاح توقيع واحتفظ به بأمان.

## تعديل الموقع

ملف الموقع موجود في `app/src/main/assets/www/index.html`. عدّل الأسعار أو النصوص فيه، ثم ابنِ التطبيق من جديد وارفع `versionCode` في `app/build.gradle.kts` عند كل تحديث على المتجر.
